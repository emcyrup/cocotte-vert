# スタッフ操作マニュアル

お店の予約・お客様情報・LINE配信をまとめて扱う管理画面の使い方です。
**アルバイトの方が初日から使えること**を目標に、画面ごとではなく「こんなときどうする」の順に書いています。

分からなくなったら、まず **[困ったとき](#困ったとき)** を見てください。

## 1. これは何をするアプリか

大きく3つです。

| できること | ざっくり言うと |
|---|---|
| **ご予約の管理** | LINEから届いたご予約を承認する。電話予約を入れる。カレンダーで一日を見る |
| **お客様・わんちゃんの管理** | 飼い主様とわんちゃんの情報、来店履歴、回数券・保育コースの残り回数 |
| **LINEの自動配信** | 前々日の確認、来店後のフォローなどを**毎朝10:00に自動で**お送りする |

自動配信は、**スタッフが何もしなくても勝手に送られます**。
止めたいときだけ操作します（→ [7. 自動でお送りしているLINE](#7-自動でお送りしているline)）。

> **覚えておくこと**
> お客様へのLINEは **毎朝10:00** にまとめて送られます。それ以外の時間に勝手に送られることはありません。

## 2. ログインする

1. ブラウザで **`https://（お店のURL）/mock/`** を開く
2. ユーザー名とパスワードを聞かれるので、店長から聞いたものを入力する

ユーザー名・パスワードは**お店で共通**です。他の人に教えたり、SNSに載せたりしないでください。

### スマホで使うとき

毎回URLを打つのは大変なので、ホーム画面に追加しておくと便利です。

- **iPhone（Safari）**: 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**: 右上の「⋮」→ 「ホーム画面に追加」

画面はスマホでも使えます。表が横にはみ出るときは、**指で左右にスワイプ**すると続きが見えます。

### メニュー

左（スマホでは上）に9つのメニューがあります。

| メニュー | 使う場面 |
|---|---|
| ダッシュボード | 朝いちばんの確認。承認待ちの件数など |
| 予約カレンダー | 一日／一週間／一か月の予定を見る。空き枠から予約を入れる |
| 予約管理 | 承認・来店登録・電話予約の登録。コースと料金表もここ |
| 顧客一覧 | 飼い主様の一覧。新規登録・電話番号の修正・リマインドの設定 |
| ペットカルテ | わんちゃんごとの詳細。来店履歴・回数券・メモ |
| リマインド | 自動配信のON/OFF（お店全体） |
| スタッフ情報・シフト | シフト入力、LINEからのシフト申請の承認 |
| SNS投稿 | Instagram・スレッズ・X・WordPress への投稿 |
| テスト送信 | お客様に送られる文面を自分で確認する |

## 3. 1日の流れ

### 朝（開店前）

1. **ダッシュボード**を開く
2. 「**承認待ちのご予約**」が0件かどうかを見る
   - 1件以上あれば「予約管理」へ。夜のうちに届いたご予約です
3. **予約カレンダー**の「日」表示で、その日の予定を確認する

### 日中

- ご来店されたら **「来店済」** にする（→ [来店されたとき](#来店されたとき)）
- 回数券・保育コースをお使いなら **「1回 消化」** を押す（→ [6. 回数券・保育コース](#6-回数券保育コース)）
- お電話でのご予約は、その場で登録する（→ [お電話でのご予約を入れる](#お電話でのご予約を入れる)）

### 閉店前

- カレンダーを見て、**来店済にし忘れ**がないか確認する
  - ここを忘れると、来店7日後のフォローLINEが届かなくなります
- 承認待ちが残っていないか、もう一度ダッシュボードを見る

### スタッフ用のLINEグループから予約を確認する

管理画面を開かなくても、**スタッフ用のLINEグループでBotに聞けば**その日の予約が返ってきます。
移動中や開店前に、スマホでさっと確認したいときに使ってください。

グループにこう送るだけです。

| 送る言葉 | 返ってくるもの |
|---|---|
| `今日の予約` | 今日のご予約一覧 |
| `明日の予約` | 明日のご予約一覧 |
| `明後日の予約` | 明後日のご予約一覧 |
| `8/20の予約` | その日のご予約一覧 |
| `20日の予約` | その日のご予約一覧（過ぎていれば翌月の20日） |
| `予約` | 今日のご予約一覧（いちばん短い言い方） |

ひらがなでも通じます（`あしたの予約`）。返信の例:

```
8月18日(火) のご予約 3件

08:00 山田様
　シャンプー＆カットコース／佐藤
13:30 田中様 ※承認待ち
　保育コース／担当未定
23:30 山田様 （来店済）
　爪切り・耳掃除／佐藤

承認待ちが1件あります。管理画面から承認してください。
```

> **見るだけの機能です。** ここから予約の承認・変更・取消はできません。操作は管理画面から行ってください。
>
> **スタッフ用のグループでしか返ってきません。** お客様とのトークや別のグループで同じことを
> 送っても、Botは何も答えません（お客様のお名前が入るため）。
> 返事がないときは、そのグループがスタッフ用として設定されていない可能性があります。店長にご確認ください。
>
> キャンセル済みのご予約は出ません。件数が多い日は30件までで、残りは管理画面に出ます。

### LINEからご予約を入れる

お電話でご予約を受けたときなど、管理画面を開かずにその場で入れられます。
**スタッフ用のLINEグループ**でも、**Botとの1対1のトーク**でも、どちらでも使えます。

「**予約登録**」とだけ送ってください。**予約登録フォームを開くボタン**が返ってきます。

```
予約登録
```

#### フォームの使い方

**① お客様を探す**

探す欄に入れて「探す」を押すと、当てはまるお客様が並びます。
**飼い主様のお名前・お電話番号・わんちゃんのお名前、どれでも探せます。**

| 入れるもの | 例 |
| --- | --- |
| 飼い主様のお名前（一部でOK） | `田中` |
| わんちゃんのお名前 | `ココ` |
| お電話番号（下4桁でもOK） | `5678` |

出てきた候補には**わんちゃんのお名前**とお電話番号の**下4桁**が添えてあります。
それで見分けて、その方を押してください。押すと上に緑色で表示されます。
違う方を押してしまったら「**お客様を選び直す**」から戻れます。

**はじめてのお客様**は「お客様が見つからない（新規で登録する）」から、
お名前だけでも登録できます。ただし**お電話番号がないとリマインドが届きません**。
分かれば入れてください（あとから顧客一覧でも足せます）。

**② ご予約の内容を入れる**

| 欄 | 入れるもの |
| --- | --- |
| 日時 | ご来店の日時。お泊まりなら**お預かり（入室）のとき** |
| コース | 選ばなくてもかまいません（「コース未定」で入ります） |
| 担当 | 開いたご自分が初めから入っています。変えられます |
| お泊まり | チェックを入れると**退室予定日**の欄が出ます |
| 所要時間 | 空欄でかまいません（コースの標準時間で入ります） |
| ご要望・メモ | 予約一覧の「ご要望・メモ」に出ます |

「**この内容で登録する**」を押すと、その場で予約カレンダーに入ります。
前々日の確認LINEの対象にもなります。

続けて入れるときは「**続けてもう1件登録する**」を押してください。
日時と担当はそのまま残るので、同じ日のご予約を続けて入れるときに楽です。

> お泊まりの退室日は、予約一覧の「ご要望・メモ」に
> 「お泊まり 2泊（8月22日(土) 退室予定）」として残ります。

#### 文章で送ることもできます

これまでどおり、1通で書いて送ることもできます。

```
予約登録 8/20 14時 田中花子 カット 担当佐藤
予約登録 8/20 14時 田中花子 お泊まり 2泊
```

送ると、Botが読み取った内容を返してきます。**中身が合っているか見てから**ボタンを押してください。

| 押すもの | どうなるか |
| --- | --- |
| **登録** | 予約カレンダーに入ります |
| **やめる** | 何も入りません。入れ直したいときは、もう一度送ってください |

ただし、お名前の読み取りは**当たらないことがあります**。うまくいかないときは、
そのまま返ってくるボタンからフォームをお使いください。そちらが確実です。

> **文章で送るときのコツ**
> - お名前は**飼い主様のお名前**で送ってください（わんちゃんのお名前では登録できません）
> - **1通に1件ずつ**送ってください
> - 時刻は「14時」「午後2時」と書くと確実です
>
> **取り消し・日時の変更はLINEからはできません。** 管理画面から行ってください。

## 4. ご予約まわり

### LINEからご予約が届いたとき

お客様がLINEから送ったご予約は、**承認するまで確定しません**。
お客様の画面には「受け付けました。確定ではありません」と出ています。**必ず当日中に返事をしてください。**

1. **予約管理**を開く
2. 予約一覧のいちばん上に、**オレンジの「承認待ち」**の行が出ています（期間の指定に関わらず先頭に出ます）
3. カレンダーで空いているか確認する
4. ボタンを押す

| ボタン | 押すとどうなるか |
|---|---|
| **承認** | ご予約が確定し、飼い主様へ「確定しました」のLINEが自動で届きます |
| **見送り** | 飼い主様へ「今回は見送らせていただきます」のLINEが自動で届きます |

> **注意**
> どちらのボタンも、押した瞬間にお客様へLINEが届きます。押す前に確認のダイアログが出るので、**わんちゃんのお名前と日時を読んでから** OK を押してください。
> 「日程だけ変えたい」場合は、見送りではなく**お電話でご相談**してから操作してください。

### お電話でのご予約を入れる

やり方は2通りあります。**カレンダーの空き枠をタップする**ほうが早いのでおすすめです。

#### 方法A：カレンダーの空き枠をタップする（おすすめ）

1. **予約カレンダー**を開き、「日」または「週」表示にする
2. 入れたい**時間の空いているところをタップ**する
3. 出てきた入力欄を埋める

| 項目 | 入れかた |
|---|---|
| 飼い主様 | 一覧から選ぶ（見つからなければ先に[新規登録](#新しい飼い主様を登録する)） |
| コース | シャンプー、カットなど |
| 担当 | 決まっていなければ「担当未定」でOK |
| 日付 | タップした日が入っています |
| 開始時刻 | タップした時刻が入っています |
| 終了時刻 | コースの標準時間で入っています。**長くかかりそうなら伸ばしてください** |

4. 「保存」を押す

> 終了時刻が開始時刻より前だと保存できません。エラーが出たら時刻を見直してください。
> ここで入れた**終了時刻の長さがそのままカレンダーの枠の長さ**になります。実態に近づけておくと、他のスタッフが空きを判断しやすくなります。

#### 方法B：予約管理の「新規予約」から入れる

1. **予約管理** → 「新規予約」のカード
2. 飼い主名・わんちゃん名・電話番号のいずれかで検索 → 一覧から選ぶ
3. 日時・コース・担当を選ぶ
4. 「予約を登録」を押す

どちらの方法でも**スタッフ入力なので承認は不要**、そのまま確定します。
公式LINEから入れることもできます（[LINEからご予約を入れる](#lineからご予約を入れる)）。

### EPARK側の枠を閉じる（ダブルブッキングを防ぐ）

EPARKからもお客様がご予約できる状態が続くので、**この画面で入れたご予約の時間は、
EPARK側でも枠を閉じる**必要があります。閉じ忘れると、同じ時間に別のお客様が入ってしまいます。

**いまは自動で閉じています（2026-08〜）。** ご予約を入れた・直した・取り消した時点で、
システムがEPARKの管理画面を操作して枠を閉じる／開け直します。**ふだんは何もしなくて
かまいません。** 反映は**1〜2分**、取りこぼしがあっても**30分以内**にもう一度試します。

うまくいかなかったぶんだけが **予約管理** →「**EPARK未反映**」のカードに残ります。
**カードに出ているものは手で閉じてください。** 出ていなければ済んでいます。

1. カードに出ているご予約を見て、**EPARKの管理画面でその時間の枠を閉じる**
2. 閉じ終えたら、カードの**チェックを付ける**（一覧から消えます）

チェックは「やったことの記録」です。**EPARK側を閉じる前に付けないでください。**
付けてしまうと一覧から消えて、閉じ忘れに気付けなくなります。

カードには2種類が並びます。

| 見出し | やること |
| --- | --- |
| EPARK側で枠を閉じる | この画面で入ったご予約。EPARKの同じ時間を閉じる |
| EPARK側で枠を開け直す（取消・見送り分） | 取り消したご予約。閉じた枠を**開け直す** |

> **開け直しも忘れずに。** 取り消したのに閉じたままだと、その時間のご予約を取り逃がします。
>
> **日時を変えたご予約は、もう一度出てきます。** 前の時間の枠を閉じたままでは意味がないので、
> 前の枠を開け直して、新しい時間の枠を閉じ直してください。
>
> EPARKから取り込んだご予約（[下の取り込み](#他のシステムのご予約をまとめて取り込むeparkなど)）は
> もともとEPARK側にあるので、このカードには出ません。

**自動で入る仮受付の見た目。** EPARK の受付表には、こんな仮受付が入ります。

```
LINE予約 / 山田 花子 様 / ポチちゃん / 090-1234-5678 / カットコース / res=12
```

- 末尾の `res=12` は**この画面のご予約番号**です。EPARK 側で見つけた仮受付が誰のものか、
  すぐ引けます
- **お客様の情報は「院内メモ」に書いているだけ**です。EPARK 側のお客様一覧（顧客台帳）には
  何も登録しません。同じお名前の別の方に紐づけてしまうと直せないためです
- **「受付」ではなく「仮受付」のまま**にしています。仮受付の印が消えると、ご予約を
  取り消したときに「自動で入れた分」を見分けられなくなります
- 90分など2枠にまたがるご予約は、**先頭の枠にだけお名前が入ります**。2枠目は無名の仮受付です
- お名前が入らなかった場合も、**枠だけは押さえます**。ご予約を取りこぼすことはありません
- **スタッフが手で入れた仮受付（お昼休み・貸切など）は、自動では開けません。**
  自動で閉じた枠だけを覚えていて、開け直すのもそこだけです
- 営業時間の終わりをはみ出す時間（トリミングの18:00など）は、**EPARK側に枠が無いので飛ばします**

### 他のシステムのご予約をまとめて取り込む（EPARKなど）

EPARKなど別の予約システムを使っている場合、そちらから出したCSVをこの画面で取り込めます。
**予約管理**→「**予約データの取り込み**」のカードです。

1. **ファイルを選ぶ**（文字コードは自動で判別します。うまく読めないときだけ手で選んでください）
2. **列の対応づけ**を確かめる。「予約番号」「お名前」「電話番号」がどの列かを選びます
3. **状態の読み替え**を確かめる。CSVの文言をどう扱うかが出ます
4. 読み取り結果を見て「**取り込む**」を押す

一度対応づけを合わせたら「**この対応づけを保存**」を押してください。次回からは
ファイルを選ぶだけで済みます。

> **状態の読み替えは必ず見てください。** 「要確認」と付いている文言は、こちらが知らない
> 言い方です。そのままだと**「ご予約」として扱われます**。キャンセルが「ご予約」で入ると、
> 来られないお客様に確認のLINEが届いてしまいます。その場で正しいものを選び直してください。
>
> **同じファイルを二度取り込んでも予約は増えません**（予約番号で見分けています）。
> 営業終了後に当日分を出し直して取り込めば、来店済みの記録も入ります。
>
> 予約番号・お名前・電話番号・日時のどれかが抜けている行は**取り込まれません**。
> CSVの何行目がなぜ駄目だったかが画面に出るので、直してから入れ直してください。

### 来店されたとき

1. **予約管理**でその日のご予約を表示する
2. 該当の行の **「来店済」** を押す

これで最終来店日が更新され、来店7日後のフォローLINEの対象になります。

> **押し忘れると起きること**
> - 来店7日後のフォローが届かない
> - しばらくすると「休眠フォロー（最終来店から90日）」の対象になってしまう
>
> **お帰りのタイミングで押す**のを習慣にしてください。

### キャンセル・無断キャンセル

予約管理の行のボタンで記録します。

| ボタン | 使う場面 |
|---|---|
| **取消** | お客様からご連絡があってのキャンセル |
| **無断** | ご連絡なくお見えにならなかったとき（無断キャンセル） |

どちらも履歴には残ります。

### ご予約の内容を直す

日時・コース・担当・所要時間は、あとから直せます。**2か所から開けます。**

| どこから | やりかた |
|---|---|
| **予約管理** | その行の「**編集**」を押す |
| **予約カレンダー** | 予約の帯を**タップ** → 「**予約を編集**」を押す |

どちらも同じ入力欄が開きます。直して「保存」を押すと、予約一覧とカレンダーの両方に反映されます。

> **飼い主様は変えられません。** 取り違えると別のお客様の予定になってしまうためです。
> 飼い主様を間違えて登録したときは、**取消してから入れ直して**ください。
>
> 済んだご予約や取消したご予約も直せます（あとから入力の間違いに気付くことが多いためです）。
>
> カレンダーの帯を**ドラッグして動かしたり、端を引っぱって時間を変えても保存されません**。
> 時間を変えるときは「予約を編集」から日時を入れ直してください。

### コース（メニュー）を増やす・やめる

**予約管理** → 「コース・メニュー管理」。
ここに登録したものが、お客様のLINE予約フォームの選択肢になります。
使わなくなったコースは**削除せず「停止」**にしてください（過去の予約の表示が崩れないようにするためです）。
再開したいときは同じボタンが「再開」に変わっています。

同じ画面にある**料金表**は見るための一覧で、この画面からは書き換えられません。
金額が変わったときは店長に伝えてください。なお、**お客様の予約フォームには金額を出していません**（ご来店時にご案内する運用です）。

## 5. お客様・わんちゃんの情報

### 新しい飼い主様を登録する

LINE未連携の方（お電話だけの方など）を登録します。

1. **顧客一覧** → 「飼い主様の登録」
2. お名前と電話番号を入れて「登録」

> 電話番号は必ず入れてください。あとからその方がLINEで登録されたときに、**電話番号で自動的に同じお客様として紐づきます**。ここが空だと、同じ方が二重に登録されてしまいます。

続けて、その飼い主様の行にある **「＋ わんちゃん」** から、わんちゃんを登録してください。
お名前・犬種・誕生日・メモを入れます。複数頭いる場合は繰り返し押します。

### 情報を直す

**顧客一覧**も**ペットカルテ**も表になっています。行の右の **「編集」** を押すと、
**その行のすぐ下**に入力欄が開きます（画面は移動しません）。

| 直したいもの | どこから | 直せる項目 |
|---|---|---|
| 飼い主様 | **顧客一覧** | お名前 / 電話番号 / 配信停止 |
| わんちゃん | **ペットカルテ** | お名前 / 犬種 / 誕生日 / メモ |

> **飼い主様の誕生日はこの画面では入れられません。**
> 誕生日メッセージは**飼い主様の**お誕生日に届くもので、その日付は
> お客様ご自身が公式LINEの登録フォームで入れた内容を使います。
> わんちゃんの誕生日は、カルテで年齢を出すためのものです。

### ペットカルテを見る

**ペットカルテ**は、わんちゃんの一覧です。名前をタップするとカルテが開き、次のことが見られます。

- 犬種・年齢・誕生日・メモ
- 来店履歴（日付・コース・担当・その日のメモ）
- 保育コースの利用状況、回数券の残り
- 「配信停止中」などのバッジ

カットの好み、苦手なこと、注意点は**メモ**に書いておいてください。次に担当する人が見ます。

### 削除について

飼い主様の削除は**元に戻せません**。わんちゃんの情報も来店履歴も一緒に消えます。
**「もうLINEは送らないで」と言われただけなら、削除ではなく[配信停止](#特定の方への配信を止める)を使ってください。**

## 6. 回数券・保育コース

わんちゃんごとに管理します。**ペットカルテ**を開いて操作します。

### 回数券

| やりたいこと | 操作 |
|---|---|
| 回数券を買われた | 「回数券」カードの **「回数券を追加」** → 回数・有効期限・メモを入れて保存 |
| 使われた | **「1回 消化」** を押す |

残り回数は「残 ◯ 回」に出ます。期限が近いものから自動的に消化されます。

### 保育コース（月4回・月8回など）

| やりたいこと | 操作 |
|---|---|
| コースに入られた | 「保育コース」カードの **「コースに加入」** → コースと開始日を選ぶ |
| 1回使われた | **「1回 消化」** を押す |
| やめられた | **「コースを解約」** |

- 当月分の回数は**毎月1日に自動で追加**されます
- 消化は**当月分が先**、そのあと先月からの繰越分の順です
- 期限を過ぎた分は「失効した回数」に記録されます

> **消化を押し忘れないでください。** 残り回数がずれると、お客様とのやりとりで食い違いが起きます。
> 押し間違えて多く消化してしまったら、店長に伝えてください（画面からは戻せません）。

## 7. 自動でお送りしているLINE

毎朝 **10:00** に、条件に当てはまる方へ自動でお送りしています。

| 種類 | いつ送られるか | 内容 |
|---|---|---|
| 前々日確認 | ご予約の**2日前** | 来店の確認。「伺います / 変更したい」のボタン付き |
| 来店7日後フォロー | ご来店の**7日後** | お礼と経過確認。お返事は自動で内容を判定してスタッフへ通知 |
| 休眠フォロー | 最終来店から**90日** | お久しぶりのご挨拶。同じ方へは90日に1回まで |
| 誕生日メッセージ | **飼い主様の**誕生日当日 | お祝いとクーポン（2月29日生まれの方は、平年は2月28日） |

このほか、ご予約の受付・確定・見送りのお知らせは、**その場で**自動的に届きます。

### 特定の方への配信を止める

「LINEはもう送らないで」と言われたときです。

1. **顧客一覧**でその方の行の「編集」を押す
2. **「配信停止」** にチェックを入れて保存

これでその方への自動配信が**すべて**止まります。カルテに「配信停止中」の赤いバッジが出ます。

「誕生日だけはいらない」のように**種類ごとに止めたい**ときは、同じ**編集**の中にある
リマインドのチェックを外してください。

1. **顧客一覧**でその方の行の「編集」を押す
2. 下のほうに「**この飼い主様へのリマインド**」が出るので、いらない種類のチェックを外す
3. 「保存」を押す

> この設定は**飼い主様ごと**です。同じお宅で複数のわんちゃんを飼われていても、
> LINEは飼い主様に1通お送りするため、**わんちゃんごとには分けられません**。
> （ペットカルテではなく顧客一覧で設定するのはこのためです）
>
> 「**（店舗設定でOFF中）**」と付いている種類は、お店全体で止まっています。
> ここでチェックを入れても送られません（→ [お店全体で止める](#お店全体で止める)）。
>
> **前々日確認**を外すときは確認が出ます。これは営業ではなく<b>ご予約の確認連絡</b>なので、
> 外すと当日まで何もお送りしないことになります。

### お店全体で止める

**リマインド**の画面で、4種類それぞれのスイッチをON/OFFできます。「すべてON」「すべてOFF」もあります。

> **これはお店全体に効きます。** お客様1人の話であれば、必ず上の「配信停止」のほうを使ってください。
> 全体を止めるときは、**必ず店長に確認してから**にしてください。

「構想」と書かれているものはまだ動いていません（触れないようになっています）。

### 送られる文面を自分で見てみる

**テスト送信**の画面から、実際の文面を確認できます。**飼い主様には届きません。**

1. お客様、またはご予約を選ぶ
2. 見たい種類のボタン（前々日確認、誕生日メッセージ など）を押す

画面の上に緑や灰色のバッジで、いま送れる状態かどうかが出ています。「テスト用アカウントへ実際に届きます」と書いてあれば、お店のテスト用LINEで実物が見られます。

## 8. シフト

**スタッフ情報・シフト**の画面です。

### シフトを入れる

表のマスをクリックするたびに、次の順で切り替わります。

**出勤 → AM半休 → PM半休 → 公休 → 有休 → 時間休 → （空欄）**

時間休を選ぶと、開始・終了の時刻を聞かれます。
表示する週は「前へ / 今週 / 次へ」または日付欄で変えられます。

入れたシフトは**予約カレンダーに反映されます**。お休みの人の時間帯と定休日には**斜線**が入ります。

> 斜線のところも**押せば予約を登録できてしまいます**（アプリ側では止めていません）。
> 斜線の上に入れようとしていないか、登録の前に必ず見てください。

### スタッフを追加する・辞めた方の扱い

「スタッフ情報」の欄に名前を入れて「追加」。

辞めた方は、まず「編集」から**「在職中」のチェックを外して保存**してください。
予約の担当候補とシフト表から外れ、記録はそのまま残ります。**まずはこれで十分です。**

一覧からも消したい場合は、そのあと「編集」の**削除**を押します。

> **在職中の方は、予約の担当に入っていると削除できません。** 押し間違いで消えると戻せないためです。
> その方の「編集」を開くと削除ボタンは出ず、代わりに理由が書かれています。先に退職にしてください。
>
> **削除すると、その方が担当していた予約の担当が「不明」になります。**
> 誰が担当したかの記録は戻せません。削除する前に確認のメッセージで件数が出るので、必ず読んでください。
> **記録を残したいなら、削除せず「退職」のままにしておくのがおすすめです。**
>
> シフトの入力内容と、LINEからのシフト変更申請の履歴も一緒に消えます。

### LINEからシフトを申請する

連携したスタッフは、**普段の公式LINEにメッセージを送るだけ**で申請できます。文章は自由です。

> 例：`8/1 有休お願いします` / `7/31 10時から12時まで時間休もらえますか`

送ると、botが読み取った内容を返してきます。**中身が合っているか見てから**、下のボタンを押してください。

| 押すもの | どうなるか |
| --- | --- |
| **確定** | そのままシフト表に入ります |
| **保留** | いったん預かりになります。店長が見て決めます |
| **やめる** | 取りやめになります。入れ直したいときは、もう一度送ってください |

ボタンを押さずに「確定」「保留」「やめる」と**文字で返してもOK**です。

> 読み取った内容が違っていたら、**確定を押さずに「やめる」**を押して、もう一度送り直してください。

#### 連携のしかた（初回だけ）

**いちばん簡単なのは、グループのボタンから登録する方法です。**

1. スタッフ用のLINEグループで「**スタッフ登録**」とだけ送る
2. Botが**登録用のボタン**を返すので、それを押す
3. 開いた画面で**自分の名前を入力**して「この名前で登録する」を押すだけ

コードの発行はいりません。1回だけの操作です。

> **お店に登録されているお名前で入力してください。** まだ登録がない場合は、
> 入力したお名前でそのまま新しく登録されます（店長が先に登録しておかなくても大丈夫です）。
>
> **同じお名前の方がすでに登録されている場合**は、
> 「区別の付くお名前を入力してください」と出ます。
> フルネームなど、見分けの付くお名前を入れてください（例：高橋 花子）。
>
> **同じお名前の方が名簿に複数いる場合**は「ご自分はどちらですか？」と候補が並びます。
> ご自分のぶんには「あなた」と出るので、それを選んでください。
>
> **退職された方と同じお名前でも登録できます。** 前の方と姓が同じだけの別の方、
> ということがあるためです。

> **このメッセージをグループのノートに固定しておくと便利です。**
> 新しく入った方が、いつでもそこから登録できます。
> 流れてしまっても、もう一度「スタッフ登録」と送れば出てきます。
>
> **押しただけでは登録されません。** 画面を開いた時点で、その方が
> スタッフ用グループにいるかどうかを確認しています。グループにいない方は登録できません。
>
> **1つのLINEアカウントで登録できるのはお一人だけ**です。すでに登録済みのアカウントで
> 別のお名前を入れても登録できません。付け替えが必要なときは店長にご相談ください。
>
> **機種変更などでご本人が登録し直したい**ときも、店長にご相談ください。
> スタッフ情報の「編集」から LINE ID を空にすると、登録し直せるようになります。

うまくいかないときは、これまでの方法も使えます。

- スタッフ情報の **「連携コード発行」** を押し、出てきた**6桁の数字を本人が公式LINEへ送る**
- スタッフ用のLINEグループで、本人が「**スタッフ登録 高橋**」のように名前を送る
- LINE ID が分かっていれば「編集」から直接入力する

#### 保留になった申請の判断（店長・責任者向け）

申請は「シフト変更の申請」に届きます。状態が3通りあります。

| 状態 | 意味 | すること |
| --- | --- | --- |
| **本人の返事待ち** | botが内容を返したが、本人がまだ答えていない | 基本は待つ（急ぐときは代わりに承認・却下できます） |
| **本人が保留** | 本人が迷って預けてきた | **承認**か**却下**を押す |
| **反映済み／取りやめ** | 決着済み | 何もしなくてかまいません |

**承認**を押すとシフト表に反映され、本人へLINEで結果が届きます。**却下**でも本人へ届きます。

> 申請の文章はAIが読み取っています。**「原文」を必ず確認**してから承認してください。読み違いがあれば却下して、口頭で確認してください。

## 9. SNS投稿

**SNS投稿**の画面から、Instagram・スレッズ・X・WordPress に投稿できます（使える先は店舗の設定によります）。

### 投稿のしかた

1. 「写真を追加」で写真を選ぶ（WordPress だけに出すなら、写真なしでもかまいません）
2. 右の**「投稿先」**で、出したい先にチェックを入れる
3. 投稿先ごとに**本文**を書く（「✨ 自動で書く」で下書きも作れます）
4. 投稿先ごとに**写真**と**タイミング**を選ぶ
5. **「選択した投稿先へ送る」**を押す

**本文もタイミングも投稿先ごとに別々**です。たとえば「Instagram はいま、スレッズは夜7時」も
「Instagram は全部の写真、スレッズは選んだ2枚だけ」もできます。

| 選ぶもの | 内容 |
|---|---|
| 写真 | **すべて**（今ある写真ぜんぶ）／**チェックした分**（写真の左上にチェックを入れたものだけ）|
| タイミング | **今すぐ**／**日時指定**（その時刻になると自動で投稿されます）|

投稿先の名前の横のバッジで、いまの状態が分かります。

| バッジ | 意味 |
|---|---|
| **実投稿** | 押すと本当に投稿されます |
| **dry_run** | 送信の練習中。実際には投稿されません |
| **未設定** | まだ使えません（チェックできません）。使いたいときは店長へ |

> Instagram は1投稿10枚までなので、**11枚以上は自動で2投稿に分かれます**（2つ目に「つづき（2/2）」が付きます）。
> ほかの投稿先は上限を超えたぶんは載りません（スレッズ20枚・X 4枚）。
>
> 1か所が失敗しても、ほかの投稿先は止まりません。結果は画面下の**投稿履歴**で確認できます。

### キャプションを自動で書いてもらう

文章が思いつかないときは、投稿先ごとの **「✨ 自動で書く」** を押してください。
その投稿先に出す写真を見て、本文の下書きを作ります。

- 「補足・記事にしたい内容」に状況を入れておくと、それに沿って書きます（例：`今日は保育コースの遠足`）
- **投稿先ごとに長さを変えて書きます**（スレッズやXは短め）
- すでに文章が入っているときは、置き換えていいか確認が出ます

> **必ず読んでから送ってください。**
> 写真から見えることをもとに書いているだけなので、**わんちゃんの名前・犬種・年齢は書きません**（間違えないため）。
> 入れたい場合はご自身で書き足してください。事実と違うところがあれば直してから送ります。

### 写真なしで、お知らせだけを投稿する（WordPress）

お休みのお知らせなど、**写真の無い記事**も出せます。Instagram とスレッズは写真が要るので、
この使い方ができるのは **WordPress**（と X）だけです。

1. 写真は1枚も選ばない
2. 「**補足・記事にしたい内容**」に、お知らせしたいことを書く。URL もここに書いてかまいません
3. WordPress の「**✨ 自動で書く**」を押す
4. できた下書きを読んで、直してから投稿する

```
例）お盆休み 8/13〜16 はお休み／16日はお昼から営業／詳しくは https://example.com/news
```

> **ここに書いたことだけをもとに書きます。** 日にちや料金を勝手に足したりしないので、
> **伝えたいことは全部この欄に書いてください。** 書いていないことは記事にも出ません。
>
> URL はそのままの形で記事に残り、**記事の中でリンクになります**（押せるようになります）。
>
> 写真ありのときと同じで、**下書きです。必ず読んでから送ってください。**

### 投稿履歴

下の「投稿履歴」で、いつ・どこへ・何枚投稿したかが見られます。予約投稿は5分おきにチェックされ、時刻を過ぎたものから投稿されます。失敗するとスタッフへ通知が届き、ここから取消・再投稿ができます。

> **写真に写り込みがないか確認してください。** 他のお客様のわんちゃん、カルテやモニターの画面、住所や電話番号のメモなどが写っていないか、投稿前に必ず見てください。

## 11. やってはいけないこと

- **お客様の削除**を、確認なしにしない。元に戻せません。配信を止めたいだけなら「配信停止」
- **リマインドの「すべてOFF」**を勝手に押さない。お店全体の配信が止まります
- **承認・見送りのボタンを、内容を読まずに押さない**。押した瞬間にお客様へLINEが届きます
- **ログインのユーザー名・パスワードを人に教えない**。SNSや写真に写り込ませない
- **お客様のお名前・電話番号・カルテの画面を撮影して外部に送らない**
- **「EPARK未反映」のチェックを、EPARK側を閉じる前に付けない**。一覧から消えて閉じ忘れに気付けません
- 分からない操作は、**押す前に**店長に聞く

## 困ったとき

### 画面の上に「新しい画面があります。表示が古いままです。」と出た

アプリが新しくなっています。帯の中の **「再読み込み」** を押してください。
ずっと開きっぱなしのタブだと古い画面のままになることがあります。**朝いちばんに一度再読み込み**する習慣にしておくと確実です。

### ボタンを押しても何も起きない／表示が変

まず**再読み込み**（スマホなら画面を下に引っ張る、PCなら F5）を試してください。
それでも直らなければ、一度ログインし直してください。

### LINEグループで「今日の予約」と送っても返事がない

- **スタッフ用のグループで送っていますか**（お客様とのトークや別のグループでは返事をしません）
- そのグループがスタッフ用として設定されているか、店長にご確認ください
- 「今日の予約」「明日の予約」「8/20の予約」のような言い方かどうか。ふつうの会話には反応しません

### スタッフを削除できない

**在職中**の方が予約の担当に入っていると削除できません。先に「編集」から
**「在職中」のチェックを外して保存**してください。退職にすれば削除できます。

ただし、担当候補とシフト表から外すだけなら退職にするだけで十分です。
削除すると予約の担当が「不明」になり、記録が戻せません。

### スタッフ登録の画面で名前を入れても登録できない

出てきたメッセージで原因が分かります。

| 出たもの | 意味と対処 |
|---|---|
| 「ご自分はどちらですか？」と候補が出た | 同じお名前の方が複数います。ご自分を選んでください |
| 「区別の付くお名前を入力してください」 | 同じお名前の方が既に登録済みです。フルネームなどで入れ直してください |
| 「すでに別のスタッフとして登録されています」 | このLINEは別の方として登録済みです。店長にご相談ください |
| 「スタッフ用のLINEグループに参加している方のみ」 | グループに参加してから、もう一度ボタンを押してください |

### 「スタッフ登録」と送ってもボタンが出ない

- **スタッフ用のグループ**で送っていますか（別のグループでは出ません）
- 「スタッフ登録」だけで送ってください。名前を付けると、これまでどおり名前での登録になります

### 登録画面で「スタッフ用のLINEグループに参加している方のみ」と出る

その方がスタッフ用グループの参加者として見えていません。グループに参加してから、
もう一度ボタンを押してください。それでも出る場合は店長にご相談ください。

### 「予約登録 …」と送っても返事がない／読み取れないと返ってくる

- **「予約登録」で始めていますか**。ふつうの文章では反応しません（お客様の発言を予約にしないためです）
- 1対1のトークで送っている場合、**スタッフとして連携済み**である必要があります（連携のしかたは8章）
- グループで送っている場合、**スタッフ用のグループ**かどうかをご確認ください
- 「読み取れませんでした」と返るときは、**お名前・日付・時刻**のどれかが足りていません。
  時刻は「14時」「午後2時」のように書くと確実です
- 「**飼い主様のお名前で送ってください**」と返るときは、わんちゃんのお名前だけになっています
- 「**1件ずつ送ってください**」と返るときは、1通に予約が2件以上書かれています
- **読み取りがうまくいかないときは、一緒に返ってくるボタンからフォームをお使いください。**
  お客様を探して選ぶので、読み取りに左右されません

### 予約登録フォームで「スタッフ用のLINEグループに参加している方のみ」と出る

その方がスタッフ用グループの参加者として見えていません。グループに参加するか、
**スタッフ登録**（8章）を済ませてから開き直してください。

### 予約登録フォームで、お客様が見つからない

- お名前は**一部だけ**でも探せます（「田中花子」でなく「田中」でも出ます）
- **わんちゃんのお名前**でも探せます
- お電話番号は**下4桁だけ**でも探せます
- それでも出ないときは、まだ登録のないお客様です。
  「お客様が見つからない（新規で登録する）」からお名前を入れてください

### 「予約を登録しました」が返ってこない

登録の返事が返るまでは**入っていません**。「登録に失敗しました」と返った場合も入っていないので、
お手数ですが管理画面から入れてください。時間が経ったボタン（24時間以上前）は押せません。

### CSVの取り込みで、文字化けする／読めない

「文字コード：自動」でうまくいかないときは、**Shift_JIS** か **UTF-8** を手で選んで入れ直してください。
それでも見出しが化けるときは、CSVを出し直すか店長にご相談ください。

### CSVを取り込んだのに、キャンセルが「ご予約」で入ってしまった

「状態の読み替え」で「要確認」が付いていた文言を、そのまま取り込んだ可能性があります。
予約一覧からその予約を**キャンセルに直し**、次回からは取り込む前に読み替えを選び直してください
（「この対応づけを保存」を押しておけば、次回から覚えています）。

### 「データの読み込みに失敗しました」と出た

インターネットの接続を確認して、再読み込みしてください。
何度も出るときは店長へ連絡してください（店員側では直せません）。

### お客様に「LINEが届いていない」と言われた

順番に確認してください。

1. その方は**LINE連携済み**か（顧客一覧の「LINE」の欄）
   - 未連携なら、そもそも届きません。公式LINEの友だち追加をご案内してください
2. その方が **「配信停止中」** になっていないか（カルテの赤いバッジ）
   - お客様ご自身が登録フォームで**配信の同意のチェックを外している**と、この状態になります
3. **リマインド**の画面で、その種類がOFFになっていないか
4. 「来店済」を押し忘れていないか（来店後のフォローが飛ばない原因の大半はこれです）
5. 誕生日メッセージの場合は、**飼い主様が登録フォームで誕生日を入れているか**
   - 未入力の方には送られません。ご案内して登録していただいてください

ここまで見て原因が分からなければ店長へ。

### 承認を押したあとに、日程を変えたいと言われた

予約管理でその予約を **「取消」** にしてから、**新しい日時で登録し直して**ください。
そのうえで、変更内容をお電話かLINEでお客様にお伝えください（**変更のお知らせは自動では届きません**）。

### 間違えて「来店済」にしてしまった

その予約を「取消」にはしないでください（キャンセル扱いの記録が残ります）。
店長に伝えてください。

### カレンダーで動かした予約が、次に見たら元に戻っている

予約カレンダー上で**ドラッグして動かす・端を引っぱって時間を変える・タップして削除する**操作は、
**保存されません**（画面上の見た目が変わるだけです）。
日時やコースを変えるときは「予約管理」から取消して入れ直してください。

### 回数を多く消化してしまった

画面からは戻せません。**いつ・どのわんちゃんの・何を何回**を控えて、店長に伝えてください。

### テスト送信のボタンを押したら「本番送信モードのためテスト送信はできません」と出た

そういう設定になっている日です。**お客様に送られてしまうことはありません**ので、そのままにして店長へ伝えてください。

### 予約が入れられない（保存できない）

- 終了時刻が開始時刻より前になっていませんか
- 飼い主様がまだ登録されていない場合は、先に[新規登録](#新しい飼い主様を登録する)が必要です
- コースが1つも登録されていないと選べません。「予約管理」の「コース・メニュー管理」で追加してください

## お客様側の画面について（参考）

お客様は公式LINEのメニューから、次の2つを使われています。スタッフが操作するものではありませんが、聞かれたときのために。

| ページ | 内容 |
|---|---|
| お客様情報の登録 | お名前・お電話番号・お誕生日（任意）・配信の同意。登録済みの方は確認・変更画面になります |
| ご予約 | 希望日時・コース・担当・ご要望を送る。**送った時点では確定しません**（スタッフの承認待ち） |

「予約できましたか？」と聞かれたら、**「承認するまで確定ではない」**とお伝えして、予約管理で承認してください。
